📖 About This Tool

Task4-attack-sim serves as a training platform for cybersecurity students and enthusiasts. It combines common testing software into one workflow. You use it to practice security testing in a controlled environment. The tool manages Metasploit, Hydra, and John the Ripper to show how these programs interact during an evaluation.

⚙️ System Requirements

Your computer needs the following specifications to run this software smoothly:

  • Windows 10 or Windows 11
  • 4 GB of RAM
  • 2 GB of free disk space
  • An internet connection for initial setup

📥 How to Install and Start

Follow these steps to set up the application on your computer:

  1. Visit the project page to download the latest version.
  2. Locate the downloaded file in your downloads folder.
  3. Double-click the installer file to begin the process.
  4. Follow the prompts on your screen. Keep the default settings to ensure all components install correctly.
  5. Once the progress bar completes, find the shortcut on your desktop.
  6. Open the application to start your first simulation.

🧩 Core Features

The application integrates several modules to build a complete learning flow:

  • Metasploit Integration: Manage complex exploit sequences through an interface.
  • Credential Testing: Utilize Hydra for quick password strength checks.
  • Password Analysis: Deploy John the Ripper to learn about hash identification.
  • Phishing Simulation: Create templates to understand human-based security gaps.

💡 Usage Guidelines

This software works best for learning and demonstration. Use it only on systems you own or have permission to test. Training helps you build skills that apply to real security roles. Always keep your environment isolated while you test new concepts.

🛠️ Troubleshooting

If the application fails to open, ensure you have Java installed on your computer. Occasionally, antivirus software might block the application. You may grant an exception if you trust the files you downloaded. Reach out to the project repository page if you encounter recurring errors.
